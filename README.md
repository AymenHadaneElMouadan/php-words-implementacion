# PHP Words

Listado local de palabras reservadas de PHP, organizado por categoría. No requiere instalación, servidor ni conexión a Internet.

## Cómo ejecutar

Pendiente de documentar

## Estructura

- `index.html`: página y carga de scripts.
- `css/estilos.css`: presentación de la lista.
- `js/config.js`: título, subtítulo y versión.
- `js/palabras.js`: palabras y descripciones.
- `js/app.js`: renderizado y aplicación de filtros.
- `notas.txt`: notas de la actividad.
